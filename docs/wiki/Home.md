# star-recommendation

**Рекомендательный сервис банка «Стар»** — сервис, который подбирает клиентам банка новые банковские продукты
и помогает сотрудникам предлагать персонализированные услуги.

## Краткое описание

Сервис анализирует операции клиента по продуктам банка (дебетовые, кредитные, накопительные и инвестиционные)
и выдаёт список подходящих продуктов. Работает по трём каналам:

- **REST API** — `GET /recommendation/{user_id}` возвращает рекомендации для клиента;
- **Telegram-бот** — команда `/recommend username` показывает рекомендации по имени пользователя;
- **Управление правилами** — менеджер без перезапуска сервиса добавляет и удаляет *динамические правила*
  рекомендаций и смотрит, как часто они срабатывают (`/rule`, `/rule/stats`).

Три продукта из первого технического задания (Invest 500, Top Saving, Простой кредит) зашиты в код как
*фиксированные правила* и работают вместе с динамическими.
Для внешних систем есть служебные методы: сброс кешей и информация о версии (`/management/*`).

## Стек технологий

| Область | Технологии |
|---------|-----------|
| Язык и платформа | Java 17, Spring Boot 3.3 |
| Веб | Spring Web (REST), Bean Validation |
| Данные о клиентах | H2 (встраиваемая файловая БД, только чтение), Spring JDBC (`JdbcTemplate`) |
| Правила и статистика | PostgreSQL, Spring Data JPA (Hibernate), Liquibase |
| Кеширование | Caffeine |
| Telegram | java-telegram-bot-api (pengrad) |
| Сборка | Maven (Maven Wrapper) |
| Тесты | JUnit 5, Mockito |
| Развёртывание БД для разработки | Docker Compose |
